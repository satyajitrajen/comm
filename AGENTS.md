## Agentic project documents

Before project work, read the applicable approved documents under `agentic/` and, for a major feature, `agentic/features/<feature-slug>/`.

Treat approved requirements and rules as authoritative. If a request conflicts with them, identify the conflict and ask whether to update the documents before proceeding. Keep `memory.md`, phase statuses, and affected documents synchronized with approved changes. Never store secrets, credentials, tokens, or sensitive personal data in project memory.
